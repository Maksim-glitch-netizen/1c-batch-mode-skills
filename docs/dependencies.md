# Внешние зависимости

В репозитории распространяются только два собственных skill. Для `1c-add-new-object` дополнительно
установи подходящий для ОС вариант [cc-1c-skills](https://github.com/Nikolay-Shirokov/cc-1c-skills)
для своего клиента: PowerShell на Windows, Python на macOS/Linux (либо отдельно проверенный PowerShell 7).
Фактические тесты выполнены только на Windows; интеграция Unix-вариантов не проверялась. Следуй README автора. Минимальный набор:

| Skill | Назначение |
|---|---|
| cf-init | Пустая donor-конфигурация; явно FormatVersion=2.20 и CompatibilityMode=Version8_3_27 |
| meta-compile | Генерация XML целевого объекта и donor-only зависимостей из object.json |
| meta-validate | Проверка XML объекта |
| cf-validate | Проверка конфигурации donor и итоговой основной конфигурации |
| db-create | Новая отдельная файловая donor-база; без AddToList и без UpdateDBCfg |

Эти зависимости не скачиваются установщиком автоматически и не входят в архив этого репозитория.
Их лицензия и установка регулируются автором. Имена могут отображаться с префиксом плагина.
Найди реальный SKILL.md и параметры его скрипта; не предполагай каталог `.codex/skills` у всех клиентов.
Для этого комплекта просмотрен интерфейс локальной PowerShell-поставки 2026.9.25+317dce6;
полный интеграционный запуск с ней при подготовке публикации не выполнялся.

Пакетный skill сам по себе не требует cc-1c-skills или MCP. Для выполнения команд нужны
установленная и лицензированная платформа 1С, доступ к выбранной базе и действующие права.
Проверка XML не заменяет синтаксическую и функциональную проверку разработанного объекта.
