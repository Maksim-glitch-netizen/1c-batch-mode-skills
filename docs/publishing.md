# Публикация

Перед публикацией запусти `scripts/validate.ps1` и просмотри `git diff --cached` или `git diff`.
В релиз входят только файлы этого репозитория: два skill, документация, лицензия, установщик и тесты.
Рабочие XML-выгрузки, базы, журналы, результаты задач и секреты не добавляются.

После создания пустого репозитория в своём Git-хостинге можно настроить remote и отправить ветку:

```powershell
git remote add origin '<URL-вашего-репозитория>'
git add .
git diff --cached --check
git commit -m 'Prepare portable 1C skills for Codex and Claude Code'
git push -u origin HEAD
```

Это инструкция для владельца; установщик и проверки не выполняют эти команды. Для установки из
Git пользователи клонируют репозиторий и запускают install.ps1 либо копируют папки skills вручную.
Для архивного релиза используй `git archive` от проверенного коммита. Файл LICENSE должен входить
в репозиторий и архив. Название и адрес удалённого репозитория выбирает владелец.

## Платформенные архивы 0.2.0

```bash
python3 -B scripts/build-releases.py --output-dir ../releases-0.2.0
```

На Windows используй python вместо python3. Команда создаёт Windows ZIP и отдельные macOS/Linux
TAR.GZ, проверяет CRC/содержимое и пишет SHA256SUMS и release-artifacts.json. Существующие
артефакты не перезаписываются. Каталог результата должен находиться вне репозитория.
**Все фактические тесты выполнены только на Windows; macOS/Linux на своих ОС не тестировались.**
Имена архивов и исполняемые биты TAR не являются подтверждением тестирования на Unix.
