# macOS

**Фактические тесты выполнены только на Windows. Этот вариант подготовлен, но на macOS не тестировался.**

Установщик: `install-macos.sh`, который вызывает общий `install.py` через Python 3.
PowerShell для установки, Python-поиска и Python-проверок не требуется.
Нужны Python 3.10+ и Bash; Git нужен для полного набора проверок.

```bash
bash ./install-macos.sh --client both --scope user
bash ./install-macos.sh --client both --scope project --project-path '/path/to/project' --dry-run
python3 -B ./scripts/validate.py
```

Установщик проверяет фактическую ОС. Каталоги клиентов те же: `~/.agents/skills` для Codex и
`~/.claude/skills` для Claude Code, либо эти каталоги внутри указанного проекта.
Существующие отличающиеся skills не перезаписываются. Права администратора и sudo не нужны.

Для `1c-add-new-object` отдельно установи Python-вариант пяти зависимых skills cc-1c-skills либо
проверь их работу через PowerShell 7. Интеграционная совместимость этих зависимостей на macOS
в этом выпуске не проверялась. Подробнее: [dependencies.md](../dependencies.md).

Для работы с 1С найди установленный бинарный файл Designer именно версии 8.3.27. Не подставляй
путь к тонкому клиенту, EDT или серверному процессу. Наличие .app/пакета платформы, архитектура
процессора и исполнимый путь проверяются на целевой машине. Этот комплект не устанавливает 1С.
Проверь допустимую аутентификацию и доступ к базе; Windows `/WA+` не переносится автоматически.
Требования графической сессии, лицензии и системных библиотек определяются установленной платформой;
комплект не гарантирует headless-запуск и не запускает виртуальный дисплей или контейнер.

Смотри [платформенные правила пакетного skill](../../skills/1c-configurator-batch-8-3-27/references/platforms.md)
и [границы проверки](../validation.md). macOS/Linux-пакеты содержат общее ядро и инструкции для всех
ОС; различаются выбранный установщик и целевая инструкция. Их названия не являются отметкой о тесте.
