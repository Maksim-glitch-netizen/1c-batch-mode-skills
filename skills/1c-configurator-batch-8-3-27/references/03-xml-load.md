# XML-загрузка: `/LoadConfigFromFiles`

## Документированные параметры

```text
/LoadConfigFromFiles <каталог>
    [-Extension <имя>]
    [-AllExtensions]
    [-files "<файл1>,<файл2>,..."]
    [-listFile <файл-списка>]
    [-Format Plain|Hierarchical]
    [-updateConfigDumpInfo]
    [-NoCheck]
    [-Archive <zip-файл>]
    [-partial]
```

## Полная загрузка

Основная конфигурация:

```text
/LoadConfigFromFiles "C:\work\xml\main"
```

Расширение:

```text
/LoadConfigFromFiles "C:\work\xml\extension" -Extension "ExtensionName"
```

Все расширения:

```text
/LoadConfigFromFiles "C:\work\xml\extensions" -AllExtensions
```

При полной загрузке формат определяется автоматически.

Ограничения:

- XML основной конфигурации нельзя загружать в расширение и наоборот.
- Если расширение подключено к хранилищу, полностью загрузить его нельзя.
- Если расширение отсутствует, `-Extension` создает его с указанным именем.

## Частичная загрузка через `-files`

```text
/LoadConfigFromFiles "C:\work\xml\main" -files "CommonModules\Module1.xml,CommonModules\Module1\Ext\Module.bsl" -Format Hierarchical
```

Список заключается в кавычки, элементы разделяются запятыми. Путь может быть абсолютным или относительным к каталогу загрузки.

## Частичная загрузка через `-listFile`

```text
/LoadConfigFromFiles "C:\work\xml\main" -listFile "C:\work\lists\load-files.txt" -Format Hierarchical
```

Файл списка:

- кодировка UTF-8;
- один путь на строку;
- абсолютные пути или пути относительно каталога загрузки;
- пустые строки не поддерживаются;
- строка, начинающаяся с `REM`, пропускается;
- переносы строк Windows и Linux поддерживаются.

Не указывай `-files` и `-listFile` одновременно. Документация описывает выбор первого параметра, но строгий сценарий не должен зависеть от порядка аргументов.

## `-Format`

При частичной загрузке автоматическое определение формата не поддерживается. Явно укажи `-Format Plain` или `-Format Hierarchical`.

`-Format` применяется только с `-files` или `-listFile`.

## `-partial`

Загружает только представленную файлом часть описания объекта. Документированы, в частности:

- описание объекта без внешних свойств;
- отдельное внешнее свойство, например форма;
- модуль формы без файла описания формы.

Не добавляй `-partial` механически ко всякой выборочной загрузке. Используй его, когда требуется загрузить именно отдельную часть объекта.

## Хранилище расширения

Для частичной загрузки в расширение, подключенное к хранилищу, загружаемые объекты должны быть захвачены в хранилище расширения.

## Остальные параметры

- `-AllExtensions` несовместим с `-files` и `-listFile`.
- `-updateConfigDumpInfo`: после загрузки создает или обновляет соответствующий `ConfigDumpInfo.xml`.
- `-NoCheck`: отключает проверку целостности. Не использовать без явного разрешения.
- `-Archive`: загрузка из ZIP. Нужно указать либо каталог загрузки, либо `-Archive`; одновременно их указывать нельзя.
