# Общая командная строка

## Шаблон

```text
<путь-к-1cv8.exe> DESIGNER <подключение> <аутентификация> <служебные-параметры> <одна-пакетная-команда>
```

В общем случае пакетные команды нельзя произвольно объединять. Явно документированное исключение для `/UpdateDBCfg` описано в `references/06-update-db-cfg.md`.

## Подключение

```text
/F <каталог-файловой-базы>
/S <адрес-серверной-базы>
/IBName <имя-базы-в-списке>
```

Для `/S` официально допустимы:

```text
server/infobase
server\infobase
"server\infobase"
```

Обратная косая черта без кавычек документирована только для Windows. Для переносимой команды заключай значение в кавычки.

## Аутентификация информационной базы

```text
/N<имя>
/P<пароль>
/WA+
/WA-
```

- `/N<имя>`: пользователь информационной базы.
- `/P<пароль>`: пароль пользователя из `/N`. Если пароль пустой, официальный источник предписывает не указывать `/P`.
- `/WA+`: требовать аутентификацию операционной системы.
- `/WA-`: запретить аутентификацию операционной системы.
- Если `/WA` отсутствует, платформа трактует это как `/WA+`.

Не добавляй пробел между `/N` и именем или между `/P` и паролем в каноническом синтаксисе документации.

## Служебные параметры

```text
/Out <файл> [-NoTruncate]
/DumpResult <файл>
/DisableStartupDialogs
/DisableStartupMessages
/@ <файл-команды>
```

- `/Out`: файл служебных сообщений. Без `-NoTruncate` файл очищается. В пакетном режиме сообщения пишутся непосредственно в файл.
- `/DumpResult`: сохраняет числовой результат Конфигуратора в файл.
- `/DisableStartupDialogs`: запрещает диалоги запуска. При недостаточных или неверных данных авторизации формируется ошибка вместо диалога. Если реквизиты хранилища не переданы, Конфигуратор запускается без подключения к хранилищу.
- `/DisableStartupMessages`: отключает перечисленные в официальной документации стартовые сообщения.
- `/@`: содержимое файла полностью заменяет командную строку приложения. Параметр должен быть первым или единственным; команда в файле записывается одной строкой.

## Обязательные условия

- Все каталоги, входящие в полный путь параметра пакетного режима, должны существовать до запуска.
- Если команда поддерживает `-Extension` и `-AllExtensions`, их одновременное применение не поддерживается, поведение непредсказуемо.
- Для расширений документирован код `0` при успехе и `1` при ошибке.

## PowerShell

```powershell
& 'C:\Program Files\1cv8\8.3.27.2214\bin\1cv8.exe' DESIGNER `
    /S 'localhost\base' `
    /WA+ `
    /DisableStartupDialogs `
    /DisableStartupMessages `
    /Out 'C:\work\logs\operation.log' `
    /DumpResult 'C:\work\logs\operation.result' `
    <ПАКЕТНАЯ_КОМАНДА>
```

## cmd.exe

```bat
"C:\Program Files\1cv8\8.3.27.2214\bin\1cv8.exe" DESIGNER ^
  /S "localhost\base" ^
  /WA+ ^
  /DisableStartupDialogs ^
  /DisableStartupMessages ^
  /Out "C:\work\logs\operation.log" ^
  /DumpResult "C:\work\logs\operation.result" ^
  <ПАКЕТНАЯ_КОМАНДА>
```
