# Захват, помещение и отмена захвата

## Важный формат `-Objects`

`-Objects` принимает официальный XML-файл списка объектов. Это не текстовый список путей XML-выгрузки.

Страница 8.3.27 с описанием формата файла в публичной английской документации не содержит отображаемой схемы. Поэтому скилл не должен генерировать содержимое такого файла по догадке. Используй существующий валидный файл, файл, сформированный Конфигуратором, или отдельный подтвержденный официальный источник формата.

## Захват

```text
/ConfigurationRepositoryLock
    [-Objects <xml-файл-списка-объектов>]
    [-revised]
    [-Extension <имя-расширения>]
```

- Без `-Objects` участвует полная конфигурация.
- `-revised`: получить захваченные объекты, если требуется.
- Для расширения укажи `-Extension` и реквизиты его хранилища.
- Документированные коды: `0` без ошибок, `1` при ошибках; текст ошибки записывается в файл служебных сообщений.

## Помещение

```text
/ConfigurationRepositoryCommit
    [-Objects <xml-файл-списка-объектов>]
    [-comment <текст>]
    [-keepLocked]
    [-force]
    [-Extension <имя-расширения>]
```

- `-comment`: комментарий в двойных кавычках. Для нескольких строк повтори `-comment` для каждой строки.
- `-keepLocked`: после помещения сохранить захват. Без параметра объекты освобождаются.
- `-force`: при ссылках на удаленные объекты выполняется попытка удалить ссылки. Без параметра формируется ошибка. Не использовать без явного разрешения.
- Документированные коды: `0` без ошибок, `1` при ошибках.

## Отмена захвата

```text
/ConfigurationRepositoryUnLock
    [-Objects <xml-файл-списка-объектов>]
    [-force]
    [-Extension <имя-расширения>]
```

- Без `-force` локально измененные объекты вызывают ошибку, операция отменяется для всех участвующих объектов.
- С `-force` локально измененные объекты получают из хранилища, локальные изменения теряются.
- Документированные коды: `0` без ошибок, `1` при ошибках.

## Правило расширения

Для каждой операции расширения одновременно должны относиться к этому расширению:

- `-Extension <имя>`;
- путь хранилища;
- пользователь и пароль хранилища;
- файл списка объектов.
