# Регистрация нового объекта через минимальный donor.cf

Историческая проверка исходного рецепта: 2026-09-17 на `8.3.27.2214` в двух новых изолированных файловых базах:
каждый процесс завершился с `ExitCode=0` и `/DumpResult=0`; `MergeCfg` сообщил об успешном
объединении, контрольная XML-выгрузка подтвердила добавление только целевого объекта.

В этой поставке живой запуск не повторялся. Исходный рецепт подтверждает сочетания ключей только для файловой базы. Для серверной целевой базы подключение
строится по согласованным параметрам подключения, а режим поддержки конфигурации определяется отдельно. Не
добавляй `-EnableSupport` или `-DisableSupport` по шаблону.

## Загрузить donor XML в рабочую конфигурацию файловой базы

```powershell
& "<полный-путь-к-1cv8.exe-8.3.27>" DESIGNER `
  /F "<папка-файловой-базы-donor>" `
  /WA+ `
  /DisableStartupDialogs `
  /DisableStartupMessages `
  /Out "<полный-путь-к-отдельному-журналу.log>" `
  /DumpResult "<полный-путь-к-отдельному-результату.result>" `
  /LoadConfigFromFiles "<папка-donor-src>"
```

Не выполнять `UpdateDBCfg`.

## Выгрузить donor.cf

```powershell
& "<полный-путь-к-1cv8.exe-8.3.27>" DESIGNER `
  /F "<папка-файловой-базы-donor>" `
  /WA+ `
  /DisableStartupDialogs `
  /DisableStartupMessages `
  /Out "<полный-путь-к-отдельному-журналу.log>" `
  /DumpResult "<полный-путь-к-отдельному-результату.result>" `
  /DumpCfg "<полный-путь-к-donor.cf>"
```

Фактический результат: существует непустой `donor.cf`.

## Объединить только разрешенный объект

```powershell
& "<полный-путь-к-1cv8.exe-8.3.27>" DESIGNER `
  /F "<папка-файловой-базы-target>" `
  /WA+ `
  /DisableStartupDialogs `
  /DisableStartupMessages `
  /Out "<полный-путь-к-отдельному-журналу.log>" `
  /DumpResult "<полный-путь-к-отдельному-результату.result>" `
  /MergeCfg "<полный-путь-к-donor.cf>" `
  -Settings "<полный-путь-к-MergeSettings.xml>"
```

В проверенном сочетании отсутствуют `-force`, `-ClearUnresolvedRefs`,
`-IncludeObjectsByUnresolvedRefs` и параметры поддержки. `MergeSettings.xml` должен разрешать
`GetFromSecondConfiguration` ровно для целевого объекта; корень и все вспомогательные объекты donor
должны иметь явное `DoNotMerge`.

## Контрольная XML-выгрузка

```powershell
& "<полный-путь-к-1cv8.exe-8.3.27>" DESIGNER `
  /F "<папка-файловой-базы-target>" `
  /WA+ `
  /DisableStartupDialogs `
  /DisableStartupMessages `
  /Out "<полный-путь-к-отдельному-журналу.log>" `
  /DumpResult "<полный-путь-к-отдельному-результату.result>" `
  /DumpConfigToFiles "<папка-контрольной-XML-выгрузки>"
```

До этой проверки не выполнять `UpdateDBCfg`. Сравнение состава используется только как
постусловие: добавлен ровно целевой объект, ничего не удалено, XML целевого объекта существует.

## Настройка подключения

Сочетание `/F` и `/WA+` выше относится к историческому тесту. Для своей базы задай согласованные
подключение и аутентификацию по `1c-configurator-batch-8-3-27/references/01-common-cli.md`.
Не заменяй ими параметры без проверки. Для повторной выгрузки в корректный каталог той же
конфигурации разрешён `-update`; контрольный запуск выполняется без `-getChanges`.
