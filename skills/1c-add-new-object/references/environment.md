# Условия выполнения

Фактические тесты выполнены только на Windows. Варианты macOS/Linux подготовлены и на своих ОС не тестировались.
Сначала прочитай [платформенные правила](platforms.md). Нужен доступ к файлам и оболочке выбранной ОС.
Для подготовительного Python-скрипта нужен Python 3.10+; для пакетных операций - установленная
платформа 1С:Предприятие 8.3.27; PowerShell используется в Windows-варианте. Другие версии платформы этим набором не подтверждены.

## Определи до начала

- полный путь к `1cv8.exe` и его фактическую версию;
- явное подключение целевой базы: `/F "<каталог>"` либо `/S "<сервер>\<база>"`;
- допустимую аутентификацию; `/WA+` подходит только при настроенной аутентификации ОС;
- каталог свежей основной XML-выгрузки (`<main-source>`);
- отдельный каталог задачи (`<task-root>`) вне установленного skill и baseline;
- тип и имя одного нового объекта, режим поддержки и правила хранилища проекта;
- доступность `cf-init`, `meta-compile`, `meta-validate`, `cf-validate`, `db-create` и второго skill
  этого комплекта. Внешние пять skills устанавливаются отдельно из cc-1c-skills.

Значения в угловых скобках - заполнители; их нельзя передавать 1С буквально. Не предполагай
существование определённой базы, пользователя, пароля, корпоративной конфигурации или префикса объектов.
Перед изменением целевой базы убедись, что запрос пользователя разрешает данную операцию.

## Выполнение и журналы

Не очищай каталоги с выгрузками и чужие задачи. При непустом workspace создай другой каталог;
не удаляй содержимое ради повторного запуска. Команда `prepare` сама проверит пустоту workspace.

На одну базу допускается один пакетный процесс Designer одновременно. Координируй запуск с другими
агентами и пользователями; встроенной межагентной блокировки в этом skill нет.
Для каждого запуска создай отдельные `/Out` и `/DumpResult`, укажи `/DisableStartupDialogs` и
`/DisableStartupMessages`. До запуска запиши назначение, команду с замаскированными секретами,
рабочую папку и время; после запуска - PID, время окончания, код процесса, оба результата и
фактические постусловия. Дожидайся завершения своего PID. Не завершай чужие процессы.

При ошибке обязательного шага останови цепочку. Не загружай частичные результаты и не запускай
автоматически повтор, откат, очистку неразрешённых ссылок или обновление БД для незавершённого каркаса.

`1c-add-new-object` не требует AgentMemory или конкретных корпоративных MCP-серверов. Если правила
пользовательского проекта требуют дополнительные инструменты, эти правила сохраняются.

## Внешние зависимости

Источник: https://github.com/Nikolay-Shirokov/cc-1c-skills
Используй текущую инструкцию автора для своего клиента и ОС: PowerShell на Windows либо Python на macOS/Linux. Последний вариант в этой поставке интеграционно не проверялся.
В этой поставке проверялся интерфейс локальных PowerShell-skills выпуска 2026.9.25+317dce6;
полный цикл 1С после подготовки этой поставки не запускался. Совместимость иных выпусков проверяется
по фактическим параметрам скриптов. Не считай установку двух skills установкой всех зависимостей.
