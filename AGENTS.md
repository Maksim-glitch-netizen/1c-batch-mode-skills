# Сопровождение репозитория

Это публикационный комплект двух Agent Skills. Рабочие файлы находятся в skills/.
Сохраняй общий стандарт SKILL.md для Codex и Claude Code, относительные ссылки, явные зависимости
и границы платформы 8.3.27. Не добавляй реальные базы, учётные данные и локальные пути автора.

Изменяй только относящиеся к задаче файлы. После изменения обнови manifest командой
`python -B scripts/update-manifests.py --write`, затем выполни `scripts/validate.ps1`.
Тесты не должны запускать 1С или обращаться к бизнес-данным. Живые проверки требуют отдельной
тестовой базы и разрешённой пользователем задачи; не подменяй их статическими результатами.

Для выпуска 0.2.1 явно сохраняй факт: все фактические тесты выполнены только на Windows.
macOS/Linux подготовлены, но на своих ОС не тестировались. Не меняй этот статус на основании
Windows-тестов, Git Bash или подготовки архивов. Проверяй также scripts/validate.py.
